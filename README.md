# COMING SOON — пиксельный мультфильм (3:00, 16:9)

Каждый пиксель и каждый звук генерируются кодом: свой растеризатор 480×270 с освещением, bloom и дизерингом,
вывод в 1920×1080 с субпиксельной камерой, воксельный 3D-рейкастер и VoxelSpace-рельеф, процедурная музыка и эффекты.

## Сборка

```bash
pip3 install pillow fonttools && python3 tools/build_font.py   # один раз: атлас пиксельных шрифтов (assets/fonts.json уже в репо)
node tools/render_all.mjs 4 out/cartoon.mp4                     # звук + 4 параллельных сегмента → MP4 (нужен ffmpeg)
node tools/preview.mjs --scene festival --n 9                   # контактный лист кадров сцены → out/preview.png
node tools/audio.mjs out/audio.wav                              # только звук
```

## Структура

- `src/core` — кадровый буфер и примитивы, спрайты, шрифты, пост-обработка, 3D (`three.mjs`).
- `src/chars` — Clawd, Codex, Gemini, Qwen и соперники (DeepSeek, Kimi, GLM) на основе исходных спрайтов, с эмоциями и позами.
- `src/world` — небо, остров-холм, лагерь, реквизит (фонарики, бенгальские огни, дистиллятор, FIREWALL…).
- `src/scenes` — 13 сцен; `src/timeline.mjs` — порядок и длительности.
- `src/audio` + `tools/audio.mjs` — синтезатор, ~75 эффектов, партитура.
